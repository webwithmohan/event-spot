NAMING CONVENTION
------------------
• Use lowercase filenames only (some web servers are case-sensitive).
• Use hyphens, not spaces or underscores, in filenames.
• Recommended formats: JPEG (.jpg) for photographs, PNG (.png) for logos/graphics.


NOTE
----
Until real images are added, the <img> tags in the HTML pages will display
their alt text (or nothing, if the browser hides broken images). Every
<img> tag already has descriptive alt text so screen readers and search
engines can understand the content without the actual image files.
