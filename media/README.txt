HOW TO CREATE THE AUDIO FILE
------------------------------
• Record a voiceover using Audacity (free – https://www.audacityteam.org) or
  any recording app, then export as MP3.
• Alternatively use a royalty-free music sample from:
    https://freemusicarchive.org
    https://pixabay.com/music/
• Recommended bitrate: 128 kbps, sample rate: 44100 Hz, stereo or mono.
• Recommended duration: 60–90 seconds.


HOW TO CREATE THE PDF BROCHURE
--------------------------------
• Design the brochure in Canva (https://www.canva.com – free), Microsoft Word,
  Adobe InDesign, or Google Slides and export as PDF.
• Suggested content:
    - Company overview and philosophy
    - List of services (weddings, corporate, parties, concerts, fests)
    - Package tiers and approximate pricing
    - Team / planner profiles
    - Client testimonials
    - Contact information and social media handles
• Save as: EventSphere-Brochure.pdf (the HTML already references this exact filename).
